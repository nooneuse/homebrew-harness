# Python 代码审查

1. 确认需要审查的文件和范围，使用文件工具读取实现；必要时查看调用方或已有测试。
2. 优先查找会导致错误行为的问题，例如空输入、越界、资源未释放或错误处理缺失。区分确定的问题与需要更多上下文才能确认的疑点。
3. 默认只做审查。只有当前用户明确要求修改时才编辑文件；需要运行命令时仍遵守宿主审批。
4. 报告必须包含以下三个部分：**结论**、**发现**、**验证情况**。
5. 每条发现包含：严重程度、文件位置、触发条件、影响与建议。位置或行号必须依据实际读取内容，不能猜测。
6. 未发现确定问题时明确说明，并交代检查范围。没有实际运行测试时，在验证情况中写“未运行测试”，不要声称已通过。

这些步骤是工作指南。当前用户要求和宿主权限优先；加载本技能不会授予额外工具权限。
